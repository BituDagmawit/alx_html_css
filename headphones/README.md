# Headphones Landing Page

This project is a responsive landing page for a headphone company, designed based on a Figma design.

## Features
- Desktop and mobile versions (switch at 480px)
- Smooth hover effects:
  - Links: `#FF6565` on hover/active
  - Buttons: `opacity: 0.9` on hover/active
- Max content width: 1000px, centered
- Uses custom fonts:
  - Source Sans Pro
  - Spin Cycle OT
- Sections:
  - Header / Hero
  - What we do…
  - Our results
  - Contact us
  - Footer
  - Hamburger menu (mobile)
- Animations on section items
- Pure HTML, CSS, and JS

## Fonts
If your computer doesn’t have the fonts used, download:
- [Source Sans Pro](https://fonts.google.com/specimen/Source+Sans+Pro)
- [Spin Cycle OT](#)

## How to Use
1. Clone the repository: `git clone <repo_url>`
2. Open `index.html` in a browser.
3. Resize window to test mobile responsiveness (<480px).
4. Hover over links and buttons to see interactions.
